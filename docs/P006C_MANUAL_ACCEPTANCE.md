# P006c 双机实验包与后续手动验收

本包为Tauri v2/WebView2 Windows x64实验版。源码包含P2P优先、TURN自动回退、720p视频及同一PeerConnection上的control.v1模拟事件；不会调用Windows键鼠注入。本轮只自动测试合成图案，没有启动真实双机桌面采集。

## 包当前状态：待激活

云端自动测试完成后，专用WSS/TURN按授权停止、不自启，测试私钥/邀请/短票清理。因此本包**不含有效凭据**，当前不能直接连接云服务。后续手动验收前，先另行授权启动专用服务及签发新临时配置；取得该配置后，将其以p006c-private.json放在RemoteHub.exe旁，两端使用同一套本轮配置。不要使用旧包的过期邀请，不安装系统根证书，不关闭TLS验证。

p006c-private.json.example仅说明配置形状，包含无效占位符，不能重命名后直接使用。共享TURN密钥、SSH密码和服务端私钥绝不进入客户端包。BUILD_INFO.json记录源码提交与程序SHA256；源代码和公开报告可从GitHub核对。

## 准备

1. 两台Windows x64电脑安装WebView2 Runtime，均可由你操作。关闭旧实验窗口；不要同时运行多个MF编码实验。
2. 第一轮两台连接同一局域网，记录双方当前网卡IPv4。第二轮再把接收端拔网线、连接手机热点；本机不更改防火墙、路由或云安全组。
3. 隐藏不希望共享的桌面内容。每轮都需要你亲自勾选同意并确认原生提示；不点击同意就不会开始桌面采集。配对码仅输入另一台程序，不能发送到聊天或日志。

## 局域网直连轮（后续另行批准）

1. 两端运行RemoteHub.exe，选择“优先直连，自动中继”，各选实际网卡、30秒；双方各填写**对方的当前IPv4**，原生提示会显示本次批准范围。
2. 发送端亲自确认，生成本轮一次性码；接收端选择接收角色，输入该码并亲自确认。
3. 保持接收端窗口可见，让30秒自然结束。观察变化画面、实际路径、发送事件/ACK是否100/100、未确认/异常是否0，等待两端资源回收完成。
4. 实际选中pair必须记录为host/srflx/relay对应类型；不能根据模式按钮推断直连。如果选择了中继，保留实际结果，不自行放宽网络校验。

## 手机热点轮（后续另行批准）

第二台拔网线，连手机4G/5G热点；两端清空局域网对端地址，重新批准并使用新配对码。其余步骤同上。实际可能P2P，也可能TURN，由真实pair决定；自然选中P2P不能当作该轮TURN证明。本次自动云测试已独立证明进程内直连受阻时的视频/control回退，但不替代真实物理NAT或双机桌面验收。

## 回传与结束

程序旁artifacts/private/p006c保留脱敏统计。先回报画面是否变化、实际路径、100/100、未确认/异常及两端错误文字；需要独立证据时再按指定方式提取统计，不发送配对码、私有配置或完整SDP。
