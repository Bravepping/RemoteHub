# Phase 0 首轮实施计划

用户请求：从交付包启动 Phase 0，生成首次工程和真实测试结果。

## 项目启动

Windows 自用桌面远控；沿用 Tauri v2 / Vue 3 / TypeScript / Tailwind / Rust，以及后续 Axum、SQLite、coturn 架构。此轮优先 P0-01、P0-02，环境允许才继续 MF 与 WebRTC；不生成虚假的设备看板，不扩展到 Phase 1。Phase 0 的两机视频和 relay 验收仍为最终出口。

## 实施与验收

1. 检测 OS、工具链、SDK、WebView2、GPU，输出 JSON；缺失项返回失败而非假通过。
2. 建立 Cargo/pnpm workspace、最小 Tauri 窗口和受限 IPC。前端构建、类型检查、测试；原生构建和窗口启动单列证据。
3. 实现 DXGI 主屏捕获实验：仅显式本机同意后捕获，有限帧数、超时、RAII 清理、输出时间戳与帧样本；检查真实 DXGI 错误。
4. 有编译环境后运行 Rust 测试和原生实验；没有则交付源码、锁文件及精确阻塞，不声明可运行。
5. 更新任务、ADR、测试报告；生成不含依赖缓存或私密截帧的源码 ZIP 和校验值。

## 边界、安全与恢复

依赖方向：Tauri -> capture，capture -> Windows SDK；测试与诊断不反向引用 UI。首轮不开放监听端口、不远程采集、不注入键鼠；本地按钮和命令的显式同意仅授权有限本机实验，不能代替远端配对与签名。尚未实现远程身份与信令时，网络远控入口保持不存在。

原交付包只读复制到独立 RemoteHub 目录；新工程 Git 记录。未发现既有代码或用户改动；只创建实际实现的模块。中断后读取 TASKS.md 和测试报告继续。源目录无需恢复；不修改系统工具链、网络、云资源。构建依赖仅在项目缓存中准备；如不能准备则记录阻塞。
