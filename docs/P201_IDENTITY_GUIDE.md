# P2-01本机身份开发与验证说明

当前只实现本机长期身份，不实现服务器登录、配对、可信设备库或签名信令。Phase 1限定退出已获用户批准，见[追加决议](PHASE1_EXIT_DECISION.md)；P2其他任务和C0兼容原型不自动开工。

## 生产行为

普通Windows版启动时初始化hub-identity，从KnownFolder LocalAppData定位RemoteHub/identity-v1。路径由Rust决定，不接受前端目录参数或环境变量覆盖；所有P0实验特性（包括纯TURN探测）均不初始化生产身份。创建新应用身份目录/文件的当前用户专用ACL，不修改既有系统安全策略。

identity.dpapi存版本化DPAPI密文；identity.lock既是跨进程独占锁，也是版本/公钥摘要提交标记。首次创建用系统CSPRNG，先保存/刷新/无覆盖发布并校验密文，再刷新提交标记，最后对外返回公开身份。已提交后密钥丢失、密文变成其他合法身份、损坏/解密失败、错格式、标记异常均停止读取，不偷偷更换设备ID。空锁加已有合法密文仅恢复同一身份，不能当作新建。

受保护根目录、锁与密钥文件检查owner/DACL、reparse属性，普通文件拒绝硬链接；持有不共享DELETE的目录句柄，锁通过Windows共享模式排他。临时密文同目录发布，无覆盖旧文件；未知pending残留保留并报错。代码不会删除生产身份或提供重置/导入/旋转入口。

桌面仅缓存ready公开ID/完整公钥SHA256指纹，或unavailable固定错误码；签名私钥随初始化对象释放并zeroize。get_runtime_info读取该缓存，不导出seed/私钥/密文/路径、不开放通用签名IPC。现有capability/CSP/命令列表不变，普通入口继续校验主窗口/允许来源。Pinia清旧字段/代次/取消/5秒上限不变；未知响应/额外字段按固定错误处理。

首页显示真实本机标识，设置显示指纹和保护/失败信息。可选择公开文本复制，没有新增剪贴板插件权限；未知状态不假填ID。标识只代表本机密钥，不表示设备在线、已配对或远控可用，remote_access_enabled仍false。

## 本地自动验证

- `pnpm verify:p201`：独立artifacts/p201，完整现有47项基础/安全/Edge/Rust/构建检查及7权限回归；含真实Windows DPAPI测试，执行者须有正常Windows用户加密配置文件。受限执行身份失败不改为明文后备，也不证明普通用户需要管理员权限。
- `python scripts/p201-native.py`：构建/测试核心并执行两个独立Rust示例进程。只允许工作区artifacts/private/p201的随机run目录，验证相同公开密钥/真实签名恢复及密文不变；输出只含布尔/进程元数据，不打印实际ID或密钥。删除前解析绝对路径并验证位于工作区且是本轮随机目录。不会启动Tauri或生产身份目录。
- `python scripts/p201-evidence.py`：离线复核计数、真实结果/隐私/范围/历史不变、锁增量和权限。历史P106/P1手动证据不刷新。

工具运行脚本的ExecutionPolicy参数和Git已知仓库信任仅在本次子进程生效，不修改系统/全局配置。已有脚本/feature及P0网络限制保持。

## 恢复与剩余范围

遇到错误保留原密文、标记和现场，不通过删除文件强制生成来“修复”。任何恢复/旋转会改变设备身份和未来信任绑定，须另定迁移合同及用户批准；本轮没有该UI/API。不要把密文/标记、完整profile路径或当前真实设备指纹复制到公开报告。

DPAPI保护的是磁盘数据，不防同Windows用户恶意代码、管理员/内存读取或整份状态删除/合法旧状态整体回滚。独立Windows账户/机器迁移、真实junction创建、原生身份页面现场操作本轮未执行；错entropy/篡改/不安全目录/硬链接负例不能替代这些测试。后续身份注册、完整公钥唯一性、设备撤销/配对和信令签名分别属于后续已规划任务。
