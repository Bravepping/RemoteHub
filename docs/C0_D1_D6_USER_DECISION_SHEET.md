## 决策记录格式与生效门槛

审查后逐项记录“选择内容、适用版本/角色、允许与禁止范围、撤销/复审条件、批准人、批准时间及对话/文档出处”。若选择改变统一UI/单安装器/权限或分发范围，先更新C0正式合同与ADR，再提交C1清单和原型计划。未签署前保持DRAFT，不下载运行组件、不安装驱动、不改路由或开启网络入口。

P1技术退出与兼容路线决策分开：用户可以批准现有WebRTC桌面框架的限定退出，同时让C0/C1继续待决；也可以把某个兼容里程碑设为退出前置。Agent不能替用户推断此选择。R06仍OPEN，不以路线切换掩盖历史可靠性风险。
