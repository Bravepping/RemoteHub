## 责任与范围

用户亲自启动指定EXE、点击窗口/五页/托盘、隐藏/恢复/退出，每一步完成后确认。Agent不自动点击、不自动启动或重复拉起程序，只编译和核验本轮唯一实例的PID、启动时间、程序SHA、可获得的窗口元数据及退出结果。窗口句柄不可得单独记UNKNOWN，不推断应用未启动/未隐藏。人工视觉结果明确记USER_CONFIRMED，进程结果独立记录。

仅普通Tauri桌面构建（custom-protocol用于内嵌前端，无p004/p005/p006/诊断feature），无媒体/云配置、真实采集、输入注入、双机、第三方后端、系统配置修改。既有严格授权/候选校验/CSP和权限不改，不启动旧探针。编译产物复制到Git忽略的artifacts/private/p106-manual/RemoteHub-P106-Manual.exe，公开manifest记录源码版本、构建参数与实际SHA；不分发配置或凭据。

## 顺序与判定

| 实例/步骤 | 用户动作（仅当前明确步骤执行） | Agent核对 | 通过依据 |
| --- | --- | --- | --- |
| A1 | 启动指定普通EXE，保持显示，不点X | SHA/唯一PID/启动时间，建立只读退出观察 | 确认本次唯一实例，不只凭窗口标题猜测 |
| A2 | 不开启驻留，点击X | 观察所绑定实例退出、退出码和同路径进程数量 | 用户窗口关闭+绑定实例真实退出，不以无句柄代替退出 |
| B1 | 按下一步指令重开，确认驻留默认未勾选 | 重新绑定新PID，旧PID已退出 | 不继承上一进程驻留 |
| B2 | 勾选本次驻留，X隐藏，先停在此处 | 同一PID仍在，记录可得句柄状态 | 用户确认隐藏/图标仍在+进程未退出 |
| B3 | 菜单显示RemoteHub，重复显示一次 | PID不变，无新实例，窗口元数据 | 用户确认显示恢复且重复显示不新建窗口/进程 |
| B4 | 再X隐藏，在托盘取消驻留 | 同一PID仍在 | 用户确认自动恢复窗口、勾选取消 |
| B5 | 点击X | 绑定实例真实退出、退出码和无残留 | 用户确认+进程证据 |
| C1 | 再开指定EXE；逐页首页/设备/连接/会话/设置，只读查看并可重新检测本机信息 | 绑定新PID，记录人工页级结果 | 五页可达/真实空态/只读检测，无连接或采集动作 |
| C2 | 按当前指令启用驻留，再通过托盘真正退出 | 绑定实例退出/退出码，无自有进程残留 | 真正退出不因勾选驻留而保留进程；图标消失由用户确认 |

同一实例PID和启动时间必须匹配；发现多个实例先停在当前步骤，由用户处理，不自动结束其他应用。Agent的只读观察器可持有目标进程句柄以获取真实退出码，观察超时仅记未得到退出结论，绝不强杀目标当成功。不存在的新PID/失去访问权/句柄为零须分别记录，不能拼出虚构PASS。

若失败，保留当前实例/时间/错误及用户原话，暂停后续操作，仅做本地只读定位。修复涉及客户端范围时先给具体原因与改动；任何采集/云/第三方或系统修改均另行申请。不会因工具找不到窗口无限重启。
