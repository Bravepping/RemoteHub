# ADR0018：P1-03未接入能力的卡片、连接弹窗与会话工具栏

日期2026-11-22，基线d0fd876。延续ADR0017的产品/实验隔离，不改网络架构、原生权限或协议。

1. 用小型自有PanelCard和LocalDeviceCard统一展示；本机只读RuntimeInfo不代表已配对设备、WS在线或远控授权。不存在的设备身份/路由/统计不填默认数据。
2. 连接准备使用浏览器内建modal dialog，利用真实焦点隔离/Escape/回焦点行为；不新增弹窗依赖或Tauri窗口。页面卸载关闭dialog，不留隐藏遮罩。打开弹窗不是开始连接，也不是原生同意。
3. 会话工作区目前无视频或活动会话，浮动工具栏仅展开/收起和本地导航可用。全屏/画质/码率/断开禁用且说明原因，不存在假事件处理器；没有键盘鼠标监听、截屏、输入注入或远程动作。
4. 不为未来IPC臆造会话状态或产品事件；真正接入后必须依真实事件显示进度、依真实selected pair与getStats显示数据，且停止入口绑定实际幂等停止。本轮未实现这些动作，不把静态准备列表当已完成步骤。
5. 测试fixture只在测试文件；产品不提供演示路由、状态切换或自动成功。原实验模板、同意、ICE/DTLS/SDP/授权/超时及CSP/capability不变；全部证据独立写artifacts/p103。

备选的自写focus trap增加维护成本，独立原生会话窗口超出本轮，因此不采用。回退为正常Git提交撤销这些UI组件，不修改历史证据；后续有真实会话数据时另行审查UI事件合同。本轮结束等待审查，不进入P1-04。
