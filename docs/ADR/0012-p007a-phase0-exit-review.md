# ADR 0012：Phase 0 技术路线保留与退出审查

日期：2026-11-22（北京时间）。审查基线：main `246dcea74f120897b47c2b6f00a7980f266afb69`。状态：**技术评估已记录；正式退出及证据例外待用户审查**。本 ADR 不授予云端启动、桌面采集、输入注入或 Phase 1 开发权限。

## 背景

原需求来自 Sunshine/Moonlight/EasyTier 使用体验，但交付规范 v1.0 §1.2–1.4 已明确选择 DXGI/MF + WebRTC/WebView2 + ICE/STUN/TURN，不实现 GameStream/Moonlight 协议兼容或通用 VPN。当前成果是基于标准 WebRTC 库的产品与会话实现，不能称作从零自研全部网络协议，也不能称作已兼容上述三款软件。

两台真实 Windows 的局域网视频、模拟控制及跨网 TURN 已有通过证据；P006c 又有云端合成源选路/受阻回退与物理双机成功轮。P004 缺原要求的录屏；P006c 两次真实候选拒绝未归因，DIAG 只完成新诊断及本机最终统计验证。

## 决议与取舍

1. **建议保留当前架构**，继续使用锁定的 webrtc/rtc 0.21.1、现有 Session、视频和 control.v1；本轮不换库、不引入 Sunshine/Moonlight/EasyTier 运行依赖。真实互通证据足以支持该路线的可行性，尚不足以承诺其延迟、连接成功率或硬件覆盖优于成熟方案。
2. 包装成熟三件套、嵌入/派生其核心、重写兼容协议均保留为评估备选，不作为这两次拒绝的修复。采用前须重新评估进程/驱动/权限/配对、升级维护、许可及迁移成本，并另立实施 ADR。一个安装器可以包装多个进程，不能据此说集成绝对不可能；它仍偏离当前单主进程和无外部运行依赖的基线。
3. 将“最低媒体技术条件已有实测”与“正式 Phase 0 退出”分开。**本轮建议暂不正式退出**：录屏偏差尚未获明确验收例外，连接可靠性尚无闭环结论；P0-04/P0-06/P0-07 父项不自动标 done。
4. P004 的视频功能通过保持有效；建议允许用户审查现有 stats + 现场观看确认作为隐私友好的录屏替代。只有明确接受该证据例外后，才可按例外收尾；当前同意不保存画面不等于已批准修改验收契约。本轮不补录、不改历史报告、不伪造录屏。
5. P006c 的严格拒绝体现安全失败，不证明存在泄露，也不证明正常环境兼容性已解决。正式退出前应取得有解释力的受控诊断/回归，或由用户明确接受限定网络覆盖和未归因风险；单纯重试成功不能关闭问题。在线复现仍按既有最小方案另行授权。
6. WebView2 若将来被实测证明存在不可接受的持续呈现延迟，优先评估保持 WebRTC/信令/控制契约的原生 D3D 渲染分支；没有测量前不切换。1080p60、真实输入、正式身份、切网恢复、长稳和发布安全继续属于后续范围，不能由本轮总评宣称完成。
