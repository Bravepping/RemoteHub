# ADR0021：原生托盘显式驻留与默认退出

日期2026-11-22，基线7f36b39。本轮仅P1-06/退出评审准备。

1. 默认X真正退出；仅本进程原生托盘菜单的主动勾选可改变为隐藏，不写配置、不自启。设置页说明入口，不新增假状态或IPC权限；后台驻留不意味着远控授权。
2. 菜单显示、退出和X统一Rust生命周期。显式退出撤销驻留并拒绝新任务，重复请求不再生成停止线程；显示不改变退出状态。取消驻留先在原生菜单主线程恢复窗口再允许采集，恢复失败转退出；普通show可能由超时工作线程调用，必须先释放策略锁再进入UI API，菜单对象克隆后也不持对象锁调度UI。图标不可用即禁止驻留，隐藏失败不声称隐藏成功。
3. 原有全部视频实验build（p004-probe及其包含者）不安装托盘、不改其停止/资源回收handler；实验关窗绝不隐藏保活。普通有界采集租约和驻留/退出受同锁约束，驻留启用或退出中不接收采集，已有租约退出前等待释放；异常未释放则显示失败，不强杀当回收成功。
4. 使用Tauri内建tray/menu feature，不引新运行时插件/前端权限。原core:default包含tray/menu全部JS默认命令，因此拆成原有path/event/window/webview/app/image/resources默认集合，明确去除JS tray/menu访问；Rust原生菜单不依赖这些JS权限。权限是收紧而非扩大，既有实验自定义权限不变。原生API驱动探针单独example复用实际处理函数与事件循环，不能当用户真实菜单点击或视频关窗释放实测；后两者没有本轮授权就保留未测。
5. 追加用户对P105原生窗口可见的确认，旧自动化定位限制仍保留。Phase1只准备证据/退出材料；R06仍OPEN、C0 D1–D6待用户，默认自研WebRTC保持，第三方不启用。

前端persist开关会新增权限/状态同步风险，故本轮选原生菜单；托盘介入实验会改变授权可见性，明确不采用。后续正式会话/托盘持久化必须另行审查，不借本轮后台驻留开启无人值守。正常提交可回退，旧报告/日志不改。
