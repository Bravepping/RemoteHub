# ADR 0017：P1-02 产品导航壳与实验界面隔离

日期2026-11-22；基线fdfb9e3；本轮仅P1-02。Tauri v2/Rust/Vue3/TS栈保持，网络协议/原生权限不变。

## 决策与取舍

1. 普通构建提供首页/设备/连接/会话/设置导航，以现有get_runtime_info只读能力为数据源；其他服务尚未接入时呈现明确空态。页面切换不是授权，不发起配对/连接/采集。
2. 当前五个本地页面无需新路由依赖，采用固定allowlist的hash路由。刷新、键盘及历史可用；未知hash回首页，不能从URL恢复会话或执行外部指令。若未来出现嵌套路由/多窗口需求，再评估正式路由库，不为本轮预装Pinia或插件。
3. 旧实验界面独立保留；显式实验feature仍进入既有授权界面，普通产品壳不呈现采集按钮。原生handler/feature范围不改。实验初值复用已取得的只读能力，不重复触发原生检测。
4. 概念图用于布局/视觉，示例设备ID、在线灯、网络健康/帧率不作为产品数据。能力读取失败清除旧值且可手动重试，不伪造0或绿灯；未知错误用可读固定反馈，不直接显示原生私密错误文本。
5. 产品样式限定作用域，保留原实验样式；默认窗口标题为RemoteHub，专用实验标题继续由原生setup设置。窗口label、CSP/capability、系统配置及锁文件均保持。

## 验证与回退

导航/失效hash/空态/异步刷新/实验分支用单元和真实Edge交互覆盖；真实默认Tauri窗口验证只读页，不点击实验或采集/输入。完整离线回归和实际原生构建独立记录，不把浏览器fixture当原生媒体数据。新UI可普通提交回退至旧壳，不删除历史实验/证据或重写Git历史。P1-03/04及三件套集成不随本ADR开工。
