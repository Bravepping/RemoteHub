# ADR 0001：先交付有限本机实验，远程入口保持关闭

日期：2026-11-21。状态：采用。未更换产品网络或媒体架构。

## 背景与选择

首轮不存在身份、配对、签名信令或会话授权实现。直接开放无认证 HTTP/SDP 接口，虽然容易演示 WebRTC，但会绕开架构基线。另一种做法是先构建完整身份服务器，会推迟最高风险的 DXGI 可用性验证。

选择有限本机原生实验：Tauri IPC 和命令行调用相同 Rust DXGI 模块，只允许当前桌面上显式同意，持续最多 5 秒（底层公共 API 最多 15 秒）、最多 300 帧。没有远程设备，也没有网络传输、SendInput 或自动后台采集。UI 不持有画面；CLI 只有显式运行才导出本地 BMP，样本排除于 Git 和交付 ZIP。

此同意只适用于本机实验，不能作为远程访问授权；未来远程媒体必须通过设备配对、签名与会话 ACL。媒体第一关卡仍为 DXGI → MF H.264 → webrtc-rs → WebView2，没有被截图或 UI 替代。

## 取舍与兼容性

独立捕获实验当前通过 CPU staging 读回完整 BGRA，便于检查 RowPitch、时间戳及画面。它不是最终的 GPU 零拷贝性能路径。不合成光标，不支持旋转输出；桌面切换/失效立即报错，需要用户重启实验。限制不影响后续接口演进，不能据此报告完整 P0-02 或视频性能已验收。

没有新增网络协议。公共 IPC 是实验接口，不承诺远控 v1 协议兼容。

## 撤销条件

完成真实身份、受信任设备、签名和 Session ACL 后，媒体入口可以接入受授权的远程会话；届时保留本机诊断入口，并重新审查权限。若 staging 成为瓶颈，记录实测后以 GPU 纹理路径替代，不改变 WebRTC 路线。
