# ADR 0016：P1-01 复用工程与构建边界检查

日期2026-11-22；基线`767ff44`。用户已接受R06有限退出风险、批准Phase0退出并只授权P1-01。本ADR为工程检查与契约整理，不改变媒体协议、依赖、原生权限或运行中会话。

## 决策

1. 复用现有Cargo/pnpm工程及锁定栈。Phase0实验模块及检查入口不删除/迁移，不因UI阶段开始改写已验证代码。
2. 新增声明式desktop构建清单，列明默认、loopback、LAN、control、TURN探针、relay、direct、R06诊断八种既有组合。用真正Cargo metadata在离线/锁定模式下核对解析feature和可选依赖，不自行实现Cargo特性解析器；全特性测试不是可分发产品构建配置。
3. `verify:p1`为Phase1统一基础检查入口，复用现有安全回归并补默认工程构建等缺口，所有本轮结果单独归档。无有效票据、采集或云脚本，框架构建本身不授予远控能力。
4. 本轮只定义[IPC与状态合同](../P101_DESKTOP_CONTRACT.md)：现有字段、原生所有权、未知统计、R06拒绝与实验隔离；不预实现Pinia、路由、后端插件或新产品IPC。后续任务按合同小步落地。
5. R06已接受为剩余风险，未修复/未关闭；严格候选、指纹、SDP、授权/过期及P004a本机限制保持。兼容目标的具体运行版本/接口/许可和进程例外仍待独立决定。

## 验证与兼容性

构建清单/检查器新增负例覆盖默认实验误启、feature串入、合成限制丢失、无解析节点；真实解析和完整离线检查结果另列。Rust/Vue主链路和旧报告不改，原自检/CLI拒绝及feature行为保持原样。回退只撤销新检查入口/当前文档，不删除原workspace、不覆盖用户配置或历史。
