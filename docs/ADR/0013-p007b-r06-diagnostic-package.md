## 已授权决议与范围

用户已明确同意：P004使用已归档真实统计及其现场观看确认替代录屏，作为本阶段限定测试范围的验收证据例外；历史未录屏事实继续保留。新增有日期决议，将P004父项按例外验收，不改旧报告，不扩大硬件/网络范围。E04关闭不代表R06关闭或Phase0退出；本轮不进入Phase1。

用户要求先准备R06最小诊断包、说明、可核对SHA256及安全回归。现在不启阿里云、不要求操作两机、不采集真实桌面。后续是否批准最多20分钟定向验证由用户单独决定。

## 设计及兼容性

1. 新增默认关闭的桌面`p007b-diag`，依赖现有`p006-direct`与`hub-webrtc/p006-session-probe`。复用`PrivateConfig::load_operator_synthetic(..., false)`、原有Session/MF合成NV12源、同一视频/control.v1 PC及认证WSS，不创造第二套网络栈。专用构建只能DirectPreferred、8秒上限；无IPC/JSON/命令行切换桌面源或注入丢包的选项。
2. 专用构建固定读取程序旁`r06-private.json`，仅接受原已校验公网IP/TLS/短期邀请格式，并把邀请剩余期限制为最多1200秒；不装信任根、不绕过证书、不自启、不携带有效配置。Loopback本地自动夹具继续用已有显式操作员探针，不能由诊断包配置启用。
3. 原生确认和界面明确“合成图案、无桌面采集”；保留本次勾选、原生确认、一次性配对/HMAC、双向路径授权、精确候选范围、停止/过期撤销。普通P004/P005/P006构建的入口和约束不变。p006-relay构建本来就不注册旧采集命令，专用构建沿用该隔离。
4. 复用DIAG的分侧拒绝原因及receiver-pre-close/receiver-final。新增专用统计目录`artifacts/private/p007b-r06`和原生记录时间/构建标识；不输出地址、端口、SDP、配对码或秘密。离线汇总工具仅导出固定字段，缺失/未知保留空值，不把旧周期计数补成最终统计。
5. 提供不联网、不读配置、不开窗口的`--r06-self-check`，让构建/打包工具核对合成源、时长、模式和feature身份；其他CLI参数拒绝。它不启动会话，也不是网络/原生GUI验收证明。
6. 交付待激活ZIP：专用EXE、核对/脱敏汇总脚本、无效配置示例、构建SHA256和操作方案。构建与安全负例、本机合成传输分开记录，未来双机结果保持NOT_RUN。本轮不新增/执行云运维脚本。

先写本ADR与诊断契约，再改源码。运行默认/全特性/专用feature的类型、lint、fmt、clippy、单元/集成及权限负例，真实本地合成源验证沿用原探针；新增配置、UI、打包错构建/含凭据拒绝、统计缺失/越权/隐私负例。构建后按实际EXE、ZIP成员和SHA验证，不把它标作新版云/双机通过。R06仍开放、正式退出待审查，完成GitHub交付即停止。
