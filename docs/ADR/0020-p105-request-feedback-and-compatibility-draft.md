# ADR0020：只读请求反馈与C0目标草案边界

日期2026-11-22，基线9418db2。本轮P1-05 + C0-DRAFT，架构栈/原生权限/网络合同保持。

1. Pinia显式区分loading、refreshing、ready、error、cancelled、idle，并拥有固定反馈；新读取立即清除runtime，不把上一轮值称作本次结果。反馈只描述本机能力读取，不映射远端在线或访问批准。
2. 用户取消当前等待显示已取消，卸载/销毁静默reset；两者均使代次失效。只读invoke本身不可撤销，晚到响应继续忽略；重试只能手动，5秒上限不变。已有实验进入条件与原生同意不变。
3. 只有BROWSER_UNAVAILABLE提及浏览器；IPC_FAILED/超时/校验失败各固定中文建议。反馈组件不渲染未知异常、错误对象message或cause；已有严格ipcFailure重建消息继续保留。
4. 全局非阻塞反馈与本地字段未知态协同；错误用alert，其余status，提供取消/重试，不提供采集或连接动作。无需通知依赖、持久化或新IPC。
5. C0合同仅草案，原生Foundation↔V+互操作和EasyTier承载为独立兼容目标；WebRTC不等于该协议实现。来源/许可/统一窗口/托管例外未批准前，不进入第三方运行原型。

保留旧值并标last-known也是可选方案，但本轮只读能力无需保留快照，清除更清晰；不为此增加历史缓存/时间戳。未来媒体统计仍按自身live/last_known/unavailable合同。原生验收只用真实默认Tauri文本与受保护的导航，不用浏览器替身代替。正常Git回退本轮UI即可，R06仍OPEN。
