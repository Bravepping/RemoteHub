## 3. 时间预算与两轮规则

| 相对 T0 | 必须完成 / 停止条件 |
| --- | --- |
| 0–3 分钟 | 核对、安装 timer、启动专用观察与 WSS/TURN、准备两机配置。耗时增加则减少轮次。 |
| 3–6 分钟 | 首轮：双方亲自原生确认，最多 8 秒合成图案，收首次原因和接收端独立统计。 |
| 6–8 分钟 | 仅在必要且前轮 Allocation 已归零时做一次对照；唯一变量须先明确，且在既有授权/候选边界内。不能为追求成功改白名单或切 relay-only。 |
| **8 分钟后** | **禁止新建会话/Allocation**，撤下本轮邀请；不再让用户点击开始。留足 600 秒真实租约及 15 秒采样宽限。新观察器也拒绝超时首次出现的新会话标签。 |
| 8–19 分钟 | 同 PID 观察已建立 Allocation 的实际释放；尽早收证后手动收尾，无须等满时限。若预算不足，标记证据不足，不续时。 |
| **19–20 分钟** | 兜底停止/清理与核对；20 分钟是不可延长的外层截止。到期停止不是单 Allocation 正常释放证据。 |

最多两轮是总尝试次数上限，包括握手失败；不能因失败而重新计数。一条会话指同时只有一对；第二轮不与第一轮重叠。当前不要求用户操作两机，获授权并完成激活后再提供短步骤。

客户端保持原同局域网物理网卡与确切对端批准；不默认切热点。每机仅打开已核对的 `RemoteHub-R06.exe`，A“发送合成图案”、B“接收合成图案”，固定 DirectPreferred / 720p30 synthetic_nv12 / 最长 8 秒，双方每轮亲自勾选并确认原生提示。配对码仅在两机间输入，不发聊天/仓库。无桌面、摄像头、麦克风采集，无实际输入；不删候选、不接受别名端点、不扩范围、不关闭严格校验。

不要求完整 240 帧或 100 ACK，不重跑 30 秒、启停矩阵或旧主动停止补测。首轮成功只收短时统计；若无需对照则结束。首轮失败先收证；新证据足够时也不强求第二轮。
