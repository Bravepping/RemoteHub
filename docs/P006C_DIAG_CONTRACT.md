# P0-06c-DIAG 契约

本轮仅增加受限本地诊断，不改变SDP/WSS/control.v1或UDP授权语义。

候选诊断version=1：local/remote独立固定原因、选中候选类型/协议/地址类别、已批准集合大小和相等关系计数；会话作用域和有效性单独判断。数据不含原始IP、端口、完整SDP、密钥、配对码或可跨会话关联的端点摘要。失败时继续拒绝，不能用诊断计数推导新的放行规则。

实际native字段为direct_pair_diagnostic：reason枚举包含matched/session_inactive/candidate_set_missing/session_scope_mismatch/protocol_rejected/component_rejected/candidate_type_rejected/address_range_rejected/type_mismatch/candidate_type_absent_from_sdp/port_changed/address_changed/endpoint_not_in_approved_sdp。多项同时不符时按检查顺序保留首要原因，并保留各相等关系计数；“变化”仅指与当前已批准集合的比较，不是网络变化历史证明。local_set_source和remote_set_source明确已发布应答/认证offer来源，private_local_publication_approved只记录本次批准布尔，不输出地址。首个失败不被后续清理或重读覆盖。

ReceiverEvidence version=1：stage=pre_close|cleanup；capture=live|last_known|unavailable；sampledAtMs为实际采样时刻、recordedAtMs为本次记录时刻；snapshot是受限视频/ICE/模拟控制统计，last_known不得改采样时间，unavailable的snapshot和采样时间为空。errors为有限数量固定安全代码；cleanup分别标原生资源、控制关闭、PC关闭、track停止，不把未知写成true。

记录在原生拥有的会话目录，只接受本地接收角色、既有会话ID和严格schema，无客户端自选路径。pre-close证据在PC/track关闭前落盘；cleanup另存并包含原生资源真实状态，不修改pre-close文件。重复/越权/超限/任意额外字段和任意字符串拒绝。数据只能用于诊断，不能授予会话或输入权限。

复用p006_save的receiverEvidence可选字段；无字段时保持旧调用。异常结束仍先尝试采样与落盘，再独立完成所有回收步骤，不能因统计失败而漏关PC。关窗限时通知前端，无响应明确记录missing/unavailable。新测试不追填旧两机893/880周期样本，不将旧失败归因为未经记录的具体原因。

文件为原生会话UUID-receiver-pre-close.json及UUID-receiver-final.json。snapshot视频及ICE来自同一份getStats报告，视频元素呈现计数和控制快照在本次收集时读取；原生nativeResourcesReleased在写入时以本地实际状态覆盖前端值。异常路径允许保存peerMatches=false的证据，但旧实时metrics校验不放宽，这些文件不参与媒体或控制授权。errors只接受固定枚举表，未知原始异常收敛为RECEIVER_INTERNAL_ERROR。IPC/采样均有界；关窗立即cancel并最多等待25秒前端落盘，再执行原有有界原生stop，缺失时由原生记unavailable。强杀/断电不保证生成文件。

用户停止时，控制发送同步revoke、原生停止请求立即异步发出，不为写盘等待延后撤销；保留浏览器PC供读取统计，再实际close。发送撤销不等于通道已关闭，cleanup.controlClosed只在实际关闭后记录。所有晚返回的周期轮询在stopped检查后退出，不覆盖最终快照或触发新批次。
