# 首轮工程的安全边界

默认没有远程访问服务。没有自动配对、信令服务、桌面视频网络传输或输入注入，也没有任意 shell IPC、权限提升或登录自启。默认 Tauri 只注册本机运行信息和有限本机采集命令。能力范围仅为本机主窗口，CSP 不允许外部页面、对象或 frame。

采集入口必须提供本次同意；UI 勾选不能持久保存，任务完成后复位。CLI 的 `--consent` 同样只授权本机实验，不能授权网络会话。界面并发实验由原子状态限制；采集帧数和时间有限。DXGI acquisition 和 mapped texture 使用 RAII 释放。

CLI 样本含当前屏幕内容：`artifacts/private/` 排除于 Git 和交付 ZIP，用户自行决定保留。默认采集实验不将画面传到 WebView。元数据不记录键鼠、访问凭据或 SDP。

显式启用 `p004-loopback` 加内嵌资源构建后，P0-04a 使用独立 WebView2 profile 和受限主窗口 IPC。每次由原生对话框允许后才建立实验会话，选中合规回环路径后才采集；只允许 127.0.0.1 上的 UDP WebRTC，不接受同网段其他设备。特殊 Chromium 参数仅在该实验窗口启用，不适用于正常构建或外部网页。实验不写画面、原始 SDP 或网络地址到磁盘或日志。

未实现的远控能力不能直接接到本机实验 API。后续必须增加 DPAPI/Ed25519 身份、手动配对、受签名信令、会话 ACL、撤销和停止，再启用远程画面或输入。服务器部署和云网络修改不属于首轮工作。
