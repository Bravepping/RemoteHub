日期2026-11-22，基线main/origin均d7ce2e0，工作区干净。已追加Phase 1限定退出批准。只实现本地Ed25519身份创建、Windows CurrentUser DPAPI持久化、重启恢复、公开身份展示及安全测试；不实现P2-02至06、信任库、联网认证或任意签名IPC。

## 实现与出口

1. 先ADR0022和身份契约；复用workspace，新增规范规划的hub-identity。固定ed25519-dalek2.2.0/Windows系统API，复用sha2/zeroize；禁止hazmat/legacy兼容，公钥只由签名密钥推导，严格验签。审查锁增量/许可证/已知漏洞，不升级原媒体依赖。
2. Ed25519 seed由Windows BCryptGenRandom产生；私钥类型不实现Debug/Serialize/Clone/导出，临时明文Zeroizing、DPAPI输出内存清零后LocalFree。只为本地自检提供固定用途/定长nonce签名，不作为后续信令协议或前端签名入口。
3. 生产目录从KnownFolder LocalAppData解析，普通构建首次启动创建；当前用户专用DACL、拒绝reparse/hardlink/超大/错版本；独占锁+同目录临时密文+不覆盖原文件的原子发布。已有文件不可解密/损坏时fail closed，不自动旋转；临时残留明确失败，不偷偷换ID。错误固定码，不含路径/私钥/密文。
4. 普通桌面初始化时读取身份，抽取公开ID/完整公钥SHA256指纹后释放私钥。现有get_runtime_info增加可选严格identity字段，前端代次/超时语义不变，capability不增加；实验构建不初始化身份，不改变实验授权/ICE/托盘清理。首页和设置只显示真实公开信息，浏览器/旧fixture未知保持空态。
5. 先写核心安全测试：签名/篡改/错公钥/弱公钥、真实DPAPI往返/错entropy/损坏、密文文件与重开稳定、并发、非法文件/ACL/残留、无明文/日志/API导出；再TS合同/UI异常测试、Edge与完整既有回归。独立进程复开在私有临时目录执行，不启动GUI或真实身份目录；记录布尔结果与脱敏计数，禁止公开真实设备标识或密钥。
6. 新artifacts/p201保存本轮证据；旧报告只读。更新README/TASKS/开发文档、许可说明与测试报告，GitHub提交后停止，不进入P2-02。

## 安全边界与恢复

DPAPI不是同一Windows用户下恶意程序/内存读取或管理员防护，不是云端身份/配对授权。短RH-ID只可展示，不作为认证唯一键；后续必须使用完整公钥。不同用户/机器实际解密失败若未现场测试则明确未测，不能以同用户错entropy测试替代。克隆整份合法旧密文/删除所有身份文件的回滚或重新注册，需要后续注册/撤销机制，本轮不声称防止。

本轮不替用户删除/重置现有身份；损坏保留原文件，先报错再另定恢复。正常Git提交回退源码不删除AppData数据。私有测试目录只清本轮确认路径，保留失败证据时不公开密文。新目录ACL仅针对本应用新身份文件，不调整系统安全配置/防火墙/服务。

规划门禁：A1–10已核对需求/出口/范围/可逆/旧成果/证据；B2依赖安全/许可、B3创建并发、B5兼容IPC/实验、B6负例、B9main→runtime→store→UI两跳、B10固定命令/无路径参数IPC、B11回读适用。无DB/全局系统变更/性能声明/不可逆删除。C每5文件写检查点。图谱无部署，rg/read复核；测试生成与自审联动，不委派子Agent。
