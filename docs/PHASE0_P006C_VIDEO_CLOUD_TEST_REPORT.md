## 范围与真实数据来源

一台物理Windows10电脑运行两个真实原生WSS客户端，发送侧为现有Rust Session/MF H264/RTP，接收侧运行现有前端RelayProbe/ControlClient与Edge真实解码。使用实际阿里云TLS/WSS、角色邀请、一次性配对、HMAC、DTLS/SRTP/SCTP和专用coturn。所有视频来自内存生成的720p30运动NV12图案，无DXGI桌面、摄像头、麦克风或实际键鼠注入，不标成物理双机或嵌入WebView2实播。

为克服本机VPN隐藏物理接口，仅测试浏览器进程使用强制合成设备和临时媒体权限后立即停掉合成流；两种云端场景均保留真正ICE服务器，没有移除TURN、没有切换relay-only或伪造pair。实际产品WebView2没有这些测试开关。原生事件中的历史字段localSynthetic指本地合成源入口；云端与否以本报告、顶层scope、真实WSS客户端及云端证据为准。

## TURN Allocation独立核对

同一个coturn PID332698，最多同时3个分配，没有超过4个上限。两个成功场景和一轮保留的统计失败共实际建立9个Allocation，每轮均清零后继续。一个WebRTC会话中浏览器多网卡gather会产生未选中的额外Allocation，不能只核对最终selected pair那一路。

两WSS角色使用同一会话用户名，观察器新增显式split-shared-credentials选项：在私有内存中按实际客户端/服务器UDP五元组关联每个Allocate及Refresh，公开仅输出顺序别名、时间戳、高端口、事务摘要、租期和socket状态；原默认行为保持。新增离线回归验证共享用户名下两条分配和各自Refresh不混淆，不将fixture当实测。

9个实际授予租约均600秒；全部有Refresh(0)请求、匹配事务的成功回应、同PID下曾存在的relay socket以及其后消失。回应后首次观察消失为1.1097–1.3967秒（500ms轮询，含观察延迟），属于refresh_zero_immediate；不是等待租约超时，更不是停整个服务制造的释放。无异常残留。

原租约及15秒宽限均已实际观察，9项对应socket在各自原租约期限及宽限后仍不存在；最后截止点为09:21:14.023469，最终在09:28:18.398695重新判断全部通过，随后才停止服务。09:21:08曾提前调用收尾脚本，被时间保护断言拦住，未发生停止/清理，最终重连同一服务器后再完成；不以提前调用当作最终成功。第一轮错误也单独计入资源核对，没有丢弃其分配或凭空标成功。
