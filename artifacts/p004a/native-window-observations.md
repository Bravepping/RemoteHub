# 原生操作观察记录（非截图/录像）

2026-11-21，Windows 原生 RemoteHub 窗口，未以独立 Edge 预览代替。

1. 通过 Windows 应用操作接口打开编译的 Tauri/WebView2 程序，初始界面显示 P0-04a、尚未开始、测量项为“未测”。初始工具窗口截图用于布局检查，未作为播放通过证据。
2. 用户亲自勾选本次同意、点击开始并批准原生 MessageBox。初版窗口实际建立到127候选、产生1–2帧编码，但发送前SPS检查失败。首版停止产生的 play AbortError曾遮蔽原始错误，修复后窗口明确显示 SPS_PROFILE_NOT_42001F。不能将这些失败记成播放通过。
3. 修正特定不适用约束位的兼容性判断后，实际读取原生窗口：AMDh264Encoder，450/450/450 输入/编码/发送，450/450/450 接收/解码/呈现，1280×720，实际选中127.0.0.1、资源已完成回收。逐轮JSON为程序输出，未手工补数。
4. 用户多次重新批准并开始；五次完整15秒均450帧，另一次完整30秒900帧。30秒窗口文字已单独保存到本机忽略目录 artifacts/private/p004-native/observed-native-window-900-frames.txt。媒体时间、收包/丢包来自原生窗口实时统计。
5. 自动接管在窗口最小化及用户输入保护下未及时完成停止，故没有把该轮900帧自动结束称为主动停止。之后用户直接在程序中完成停止与播放中关窗，Agent核对47帧 stopped=true / 两端回收和33帧 window-close / cleanupSucceeded=true。
6. 最后查询目标窗口列表为空，系统进程列表也不存在该 RemoteHub 程序。GUI OS退出码未捕获；不从“进程消失”推断它等于0。

本记录说明观察方法和证据范围；不是逐事件原始自动化日志。所有公开数字来自同目录脱敏原生/接收端JSON。未另存播放截图或视频，也没有生成图片替代实际播放证据。
